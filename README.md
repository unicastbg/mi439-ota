# Mi439 OTA Channel

Static OTA metadata for unofficial LineageOS builds for Xiaomi Mi439 variants
(Redmi 7A / Redmi 8 / Redmi 8A / Redmi 8A Dual).

The intended free hosting layout is:

- GitHub Pages from this repository serves the small JSON metadata files.
- GitHub Releases in a separate builds repository serves the signed ROM zips.

Example ROM property:

```make
PRODUCT_SYSTEM_PROPERTIES += \
    lineage.updater.uri=https://unicastbg.github.io/mi439-ota/Mi439-23.2.json
```

The built-in LineageOS Updater reads `lineage.updater.uri` and expects JSON in
the format generated by `tools/New-Mi439OtaJson.ps1`.

## Workflow

1. Build and sign the ROM zip.
2. Upload the signed zip to a GitHub Release in the builds repository.
3. Generate/update the JSON metadata:

   ```powershell
   .\tools\New-Mi439OtaJson.ps1 `
       -ZipPath "C:\path\to\lineage-23.2-20261003-UNOFFICIAL-Mi439-signed.zip" `
       -DownloadUrl "https://github.com/unicastbg/mi439-builds/releases/download/20261003/lineage-23.2-20261003-UNOFFICIAL-Mi439-signed.zip" `
       -OutputPath ".\docs\Mi439-23.2.json"
   ```

4. Commit and push this repo. GitHub Pages publishes the JSON.
5. Phones on the same LineageOS version and signed with the same keys can update
   from the built-in Updater.

## Important Notes

- Do not store ROM zips in this repository or in GitHub Pages.
- Keep ROM zips as GitHub Release assets so large downloads do not hit GitHub
  Pages bandwidth limits.
- OTA updates require consistent signing keys across builds.
- Migrating from official LineageOS signing keys to your own keys is a manual
  migration. After that, same-key builds can update normally.
- Major version upgrades are usually manual. Use OTA for same-version updates
  like `23.2` to newer `23.2` builds.
